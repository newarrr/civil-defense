# دليل لوحة الإدارة

**الرابط:** https://newarrr.github.io/civil-defense/admin/

## 1. تجهيز موظف جديد (مرة واحدة، يقوم بها صاحب المستودع)

1. يُنشئ الموظف حسابًا مجانيًا على github.com.
2. صاحب المستودع يفتح: GitHub ← `newarrr/civil-defense` ← **Settings** ← **Collaborators** ← **Add people**، ويضيف حساب الموظف.
3. الموظف يقبل الدعوة من بريده الإلكتروني.
4. الموظف يُنشئ مفتاح دخول (Token):
   - github.com ← صورة الحساب ← **Settings** ← **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens** ← **Generate new token**
   - **Repository access:** Only select repositories ← `newarrr/civil-defense`
   - **Permissions:** Contents = **Read and write**
   - احفظ المفتاح في مكان آمن ولا ترسله لأحد.

## 2. الدخول

افتح رابط الإدارة ← **Sign In Using Access Token** ← الصق المفتاح.

## 3. نشر خبر

1. **الأخبار والفعاليات** ← **الأخبار** ← **إضافة خبر** (يظهر أعلى القائمة).
2. **معرّف الرابط:** كلمات إنجليزية بشرطات، مثل `flood-drill-zakho-2026`.
3. **التاريخ** و**صورة الغلاف** (ارفعها من جهازك؛ تُصغَّر وتُحوَّل تلقائيًا إلى WebP)، ثم **وصف الصورة**.
   - **معرض الصور:** أضف صورًا إضافية تظهر أسفل الخبر.
   - **التصنيف:** خبر، فعالية، عملية ميدانية، تدريب، إعلان.
   - **منشور:** ألغِ التفعيل لحفظ الخبر كمسودة لا تظهر للزوار.
4. **الفيديو:** ارفعه على YouTube ثم الصق رابطه.
5. اكتب العنوان والملخص والنص بالعربية. افتح «بادینی» و«سۆرانی» و«English» وأضف الترجمة. اللغة الفارغة تعرض النص العربي.
   - سطر فارغ = فقرة جديدة. سطر يبدأ بـ `- ` = نقطة.
6. اضغط **Save**. يظهر الخبر على الموقع بعد دقيقة إلى دقيقتين.

يظهر أحدث خبر في أول بطاقة من بطاقات الأخبار في الصفحة الرئيسية، ويفتح في نافذة الموقع، ويظهر كذلك في قائمة «المصادر والتحديثات».

## 4. تنبيه عام (طوارئ، طقس، إلخ)

**التنبيهات العامة** ← إضافة تنبيه ← اختر المستوى (أزرق، برتقالي، أحمر)، ووقت الانتهاء إن وُجد، ثم اكتب العنوان والرسالة. يظهر شريطًا أعلى كل الصفحات. لإخفائه: ألغِ «مفعّل» أو احذفه.

## 5. الإحصائيات (أسفل الصفحة الرئيسية)

**الإحصائيات** ← لكل رقم: اكتب الرقم والفترة (مثل 2025)، ثم فعّل **معتمد من المديرية**. قبل الاعتماد تبقى العبارة الأصلية «بانتظار الاعتماد».

## 6. مراكز الدفاع المدني

**مراكز الدفاع المدني** ← إضافة مركز: الاسم والقضاء وأوقات العمل بالأربع لغات، والهاتف ورابط الخريطة. لا يظهر المركز في صفحة «حالة الخدمات» إلا بعد تفعيل **تم التحقق من البيانات**.

## 7. القائمة العلوية

**القائمة العلوية** ← غيّر مكان «آخر الأخبار» وعددها، أو أضف رابطًا لأي قائمة.

## ملاحظات

- كل تعديل يُحفظ في سجل GitHub، ويمكن الرجوع إلى أي نسخة سابقة.
- عند ترك العمل: صاحب المستودع يزيل الموظف من Collaborators، والموظف يحذف مفتاحه.
