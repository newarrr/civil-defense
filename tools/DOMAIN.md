# ربط الدومين الحقيقي (الخطوة الأخيرة)

## 1. عند شركة الدومين (صفحة DNS)

**دومين رئيسي** (مثل `example.krd`): أضف أربعة سجلات من نوع **A**:

| النوع | الاسم | القيمة |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | newarrr.github.io |

**أو نطاق فرعي** (مثل `www.example.krd`): سجل واحد فقط، من نوع CNAME، اسمه `www` وقيمته `newarrr.github.io`.

## 2. في GitHub

المستودع ← **Settings** ← **Pages** ← **Custom domain** ← اكتب الدومين ← **Save**. انتظر حتى تظهر علامة ✓، ثم فعّل **Enforce HTTPS**.

## 3. في المشروع (أقوم به أنا)

```bash
node tools/seo.mjs https://example.krd/
```

هذا الأمر يحدّث الروابط الأساسية (canonical) وروابط المشاركة وsitemap.xml وrobots.txt على كل الصفحات. بعده:
- يُحدَّث `site_url` في `admin/config.yml`.
- يُنشأ ملف `CNAME` يحتوي اسم الدومين.
- يُرفع التحديث إلى GitHub، ثم أفحص الموقع على الدومين الجديد.

## 4. بعد الربط

- **Google Search Console:** أضف الدومين ثم أرسل `sitemap.xml`.
- **الرابط القديم:** `newarrr.github.io/civil-defense` يحوّل تلقائيًا إلى الدومين الجديد.
