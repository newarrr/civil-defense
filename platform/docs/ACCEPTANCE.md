# بوابات القبول

لا يُكتب «100% مكتمل» ما لم تتحقق المنصة كلها. مرور أساس المرحلة لا يغلق المراحل المؤجلة.

| البوابة | دليل أول PR | ما يلزم للإطلاق |
|---|---|---|
| حماية الرئيسية | 115 hash + 64 مقارنة pixel/metrics/locale/theme/overflow | مراجعة أي تعديل لاحق للروابط مسبقاً |
| التصنيف | اختبارات كل بعد والتقاطع والصفر والفئات القابلة للإضافة | اعتماد التصنيف تحريرياً وربطه ببيانات الإنتاج |
| البحث | مرادفات اللهجات، حدود query/pagination، لا fallback خفي | corpus بحث واقعي ومراجعة بشرية لجودة النتائج |
| سلامة النشر | منع المصدر الناقص/القديم/غير المحلي والمراجعات الذاتية والقديمة | مراجعة مصادر ومحتوى علمية وبشرية حقيقية |
| workflow | تسعة أدوار، انتقالات، تضارب version، رفض self-review | هوية/MFA وAPI كاملة ومهام التحرير وmedia |
| DB | migration وFK وappend-only وtransaction rollback | PostgreSQL staging، least-privilege/RLS، pool وحمل وتزامن فعلي |
| اللغات | direction/lang واختبارات النصوص المفقودة | اعتماد Badini/Sorani/Arabic/English لكل إصدار |
| الإتاحة | axe AA على معاينة الأربع لغات و320/390/768/1440 | فحص يدوي keyboard/screen reader وWCAG2.2AA لكل التدفقات |
| الأداء | تقارير المتصفح؛ لا ادعاء CWV ميداني | قياس LCP/CLS/INP وموبايل ضعيف وشبكة بطيئة على الصفحات الحقيقية |
| الخصوصية | public-only snapshot، خادم loopback allow-list، لا PII جديدة | سياسة احتفاظ وAV وaudit خارجي وتهديدات جلسات |
| التعافي | rollback منطقي عند فشل DB داخل اختبارات | نسخة حقيقية واستعادة staging وتمرين RPO/RTO |
| النشر | PR منفصل وCI بلا deploy | موافقة المالك، رصد ما بعد النشر وخطة تراجع |

المقارنة البصرية تقارن baseline والفرع على نفس نسخة المتصفح والخطوط/DPR/viewport، وتنتظر فك الصور وإطارين ثابتين. لا pixel threshold ولا mask يخفي اختلافاً. لا تُحدّث baseline لتغطية فشل. الأدلة الخارجية الأصلية موثقة بالهاش، لا تعامل كصور cross-platform golden.

بيانات fixtures اصطناعية ومحصورة بالاختبارات. واجهة المراجعة تقرأ الـ16 موضوعاً القديم فقط وتعرض صراحة انتظار المراجعة؛ لا تسمية «منشور معتمد» ولا نشر تلقائي لها.
