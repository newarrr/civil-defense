# بوابات القبول

لا يُكتب «100% مكتمل» ما لم تتحقق المنصة كلها. مرور أساس المرحلة لا يغلق المراحل المؤجلة.

| البوابة | دليل أول PR | ما يلزم للإطلاق |
|---|---|---|
| حماية الرئيسية | 115 hash + 64 مقارنة pixel/metrics/locale/theme/overflow | مراجعة أي تعديل لاحق للروابط مسبقاً |
| التصنيف | اختبارات كل بعد والتقاطع والصفر والفئات القابلة للإضافة | اعتماد التصنيف تحريرياً وربطه ببيانات الإنتاج |
| البحث | مرادفات اللهجات، حدود query/pagination، لا fallback خفي | corpus بحث واقعي ومراجعة بشرية لجودة النتائج |
| سلامة النشر | منع المصدر الناقص/القديم/غير المحلي والمراجعات الذاتية والقديمة | مراجعة مصادر ومحتوى علمية وبشرية حقيقية |

| النشر | PR منفصل وCI بلا deploy | موافقة المالك، رصد ما بعد النشر وخطة تراجع |

المقارنة البصرية تقارن baseline والفرع على نفس نسخة المتصفح والخطوط/DPR/viewport، وتنتظر فك الصور وإطارين ثابتين. تشترك الصور والخطوط المتطابقة بايتياً فقط في browser cache للحفاظ على مسار raster نفسه، مع رفض أي اختلاف ثنائي مستقلاً قبل العرض. HTML/CSS/JS تُجلب من نسخة Git ثم نسخة العمل دون cache، وتمنع CSP الاختبارية الطلبات الخارجية. لا تعديل للشعار أو CSS الصورة، ولا pixel threshold ولا mask يخفي اختلافاً. لا تُحدّث baseline لتغطية فشل. الأدلة الخارجية الأصلية موثقة بالهاش، لا تعامل كصور cross-platform golden.

المحرك المرجعي للاختبار Firefox المثبت عبر Playwright على CI Ubuntu، والمعاينة الوظيفية/axe على Chromium. أظهرت تجارب Chromium/Edge تفاوتاً متقطعاً مقداره1390 بكسلاً في تصغير PNG التذييل رغم تطابق البايتات وموضع58×70 وأبعاد المصدر1254×1254 وكل خصائص العرض؛ لا نسمح به عبر threshold أو mask. نقل بوابة المقارنة لمحرك مثبت آخر لا يغيّر الموقع، ويجب أن يمر فعلياً قبل اعتماد النتيجة. تشغيل Firefox محلياً على هذا الجهاز يتطلب `msvcp140_1.dll` غير المتاحة؛ لا نثبت runtime نظام دون حاجة أو موافقة.

بيانات fixtures اصطناعية ومحصورة بالاختبارات. واجهة المراجعة تقرأ الـ16 موضوعاً القديم فقط وتعرض صراحة انتظار المراجعة؛ لا تسمية «منشور معتمد» ولا نشر تلقائي لها.
