# Duhok Civil Defense — platform foundation

هذه الإضافة جزء من المستودع الحقيقي، ولا تستبدل الصفحة الرئيسية. **لا نشر عام ولا دمج دون موافقة المالك.** جميع الملفات القديمة الـ115 مجمدة في أول PR.

ابدأ بـ[تقرير التدقيق وخريطة التنفيذ](docs/BASELINE-AUDIT.md)، ثم [المعمارية](docs/ARCHITECTURE.md)، [التشغيل والأمن](docs/OPERATIONS.md)، و[معايير القبول](docs/ACCEPTANCE.md).

## ما يعمل في هذه المرحلة

- محرك بحث وتصنيف بأربعة أبعاد، مرادفات منفصلة حسب اللغة، تقاطع المرشحات، تعداد النتائج، وترقيم الصفحات.
- عقود مصادر ومراجعات وترجمات؛ تصدير عام يسمح بالمحتوى المعتمد الحالي فقط ويمنع العلاقات نحو المسودات.
- نواة سير تحرير بست حالات، تسعة أدوار، منع المراجعة الذاتية، وإصدارات متفائلة.
- خدمة أوامر مستقلة عن الاستضافة: تقرأ الأدوار من قاعدة البيانات وتكتب الحالة والإصدار والترجمات والتدقيق في معاملة واحدة.
- مهاجرة PostgreSQL مجرّبة في PGlite داخل الذاكرة، مع علاقات ومفاتيح أجنبية وسجلات append-only؛ **لم تُنفذ على قاعدة إنتاج**.
- أداة مراجعة محلية تعرض 16 موضوعاً مستورداً من الموقع مع التصنيف المقترح والمصادر وحالة المراجعة. لا تسجيل دخول ولا إرسال بلاغ ولا زر نشر.
- حارس SHA-256 واختبار 64 حالة بصرية للرئيسية، واختبارات متصفح وإتاحة وصول للأداة الجديدة.

هذا ليس CMS متاحاً للموظفين بعد. محول الهوية الحقيقي وMFA وRLS/منح مستخدم قاعدة التطبيق ورفع الوسائط وواجهة الإدارة وexport إلى الإنتاج والنسخ الاحتياطي والاستعادة تتطلب المرحلة التالية واعتماد الخدمة.

## التشغيل المحلي

Node 24، ثم من هذا المجلد:

```sh
npm ci --ignore-scripts
npx playwright install chromium
npm run check
npm run test:review
npm run test:visual
npm run review
```

المعاينة: `http://127.0.0.1:4190/?lang=ar`، أو `badini` / `sorani` / `en`. الخادم مربوط بـ127.0.0.1 فقط ويعرض قائمة ملفات محددة. لا يعمل كخادم إنتاج. الواجهة موجودة تحت `review/` لكن `/data.json` لا يولّد إلا محلياً؛ لا توجد صفحة عامة جديدة مرتبطة بالرئيسية.

على Windows يمكن استعمال Edge الموجود للاختبارات المحلية:

```powershell
$env:PW_CHANNEL='msedge'
npm run test:review
npm run test:visual
```

CI يستعمل إصدار Chromium التابع لإصدار Playwright المثبت في lockfile؛ baseline ونسخة الفرع يُعرضان في المتصفح نفسه داخل كل تشغيل. صور الموقع المنشور ملتقطة بEdge ومفصولة عن مقارنات CI عبر الأنظمة.

## حدود البيانات

كل بيانات `test/fixtures.mjs` اصطناعية للاختبارات فقط، ولا تُحمّل في المعاينة أو الموقع. بيانات المعاينة من ملفات المعرفة القديمة المجمدة، وتبقى كلها `pending-human-review`؛ التصنيفات اقتراحات استيراد تحتاج اعتماداً. لا تُغيّر الأداة النصوص الأصلية ولا تعتبر مصدرها أو ترجمتها معتمداً.

لا مفاتيح، لا حسابات إنتاج، لا تتبع مستخدمين، ولا معلومات حوادث أو موظفين حقيقية في هذه الإضافة. لا يمكن اعتبار مرور الاختبارات مراجعة لغوية كردية أو مراجعة علمية أو شهادة WCAG/ASVS.

## الأدلة

- `evidence/legacy-files.json`: hashes وأحجام كل الملفات الأصلية ونقطة التثبيت.
- `evidence/legacy-git-files.json`: hashes لنسخة Git الأصلية؛ يقبل الحارس تمثيلي checkout الموثقين CRLF/LF فقط، دون تطبيع يخفي تعديل المحتوى.
- `evidence/public-reference.json`: 64 لقطة عامة وقياساتها وhash لكل لقطة وحالة المتصفح.
- `evidence/inventory.json`: جرد فعلي للملفات والمحتوى؛ ماسح storage لم يلتقط مفتاح الثيم المتغير، وقد وُثق يدوياً في التدقيق.
- `test-results/`: صور قبل/بعد والفروق والتقارير، تجاهلها Git. CI يرفعها كartifacts لمدة محدودة.
- `docs/PHASE-REPORT.md`: نتائج التسليم الفعلية وحدودها.
